# Module 8: Sub-Agents
**Complexity: Medium** — Additive work on existing streaming infrastructure. Single-pass executable with clear extension points.

---

## Goal

Introduce an **orchestrator-worker sub-agent pattern** where the main chat agent detects "full-document analysis" scenarios and delegates to an isolated `DocumentAnalystAgent`. The agent streams its reasoning and tool usage in real-time. The UI displays nested tool calls in a collapsible activity block.

**Key concepts taught:**
- Context isolation — sub-agent receives only (document + task), never full chat history
- Orchestrator delegation — when/why the main agent hands off to a specialist
- Hierarchical agent display — UI shows orchestrator → sub-agent nesting
- Real-time sub-agent streaming — SSE bridging from inner agent to outer stream

---

## Architecture Overview

```
User query
  └─► MainAgent (chat_service.py)
        ├─► RAG retrieval (existing)
        ├─► tool: query_documents_sql (existing)
        ├─► tool: search_web (existing)
        └─► tool: analyze_document  [NEW]
               └─► DocumentAnalystAgent (agent_service.py) [NEW]
                     ├─► Isolated context (document only, no chat history)
                     ├─► tool: search_document_chunks [NEW, scoped]
                     └─► Returns structured result → main agent uses in Pass 2
```

### SSE Event Protocol Extension

Existing events:
```
data: __sources:{count}
data: __tool:{tool_name}
data: {token}
data: [DONE]
```

New events for sub-agent visibility:
```
data: __agent_start:{agent_name}        # Sub-agent begins execution
data: __agent_thinking:{text}           # Sub-agent CoT reasoning (URL-encoded)
data: __agent_tool:{tool_name}          # Sub-agent tool call
data: __agent_end:{agent_name}          # Sub-agent completes
```

**Encoding rule:** `__agent_thinking` text is URL-encoded (`urllib.parse.quote`) to avoid `\n` breaking SSE framing. Frontend decodes with `decodeURIComponent`.

```python
class DocumentAnalystAgent:
    """
    Isolated sub-agent for full-document analysis.
    Context: (document chunks joined) + task. No chat history.
    Tools: search_document_chunks only.
    Max loop: 3 iterations.
    """

    TOOL_DEFINITIONS = [
        {
            "type": "function",
            "function": {
                "name": "search_document_chunks",
                "description": "Search within a specific document using semantic similarity. Use this to find relevant passages when answering the task.",
                "parameters": {
                    "type": "object",
                    "properties": {
                        "query": {
                            "type": "string",
                            "description": "The search query to find relevant passages"
                        }
                    },
                    "required": ["query"],
                    "additionalProperties": False
                }
            }
        }
    ]

    def __init__(self, document_id: str, task: str, user_id: str):
        self.document_id = document_id
        self.task = task
        self.user_id = user_id

    async def _search_document_chunks(self, query: str) -> str:
        """Scoped vector search within one document only."""
        # Calls retrieval_service.retrieve_context() with filter_document_ids=[self.document_id]
        # Returns formatted context block or "No relevant passages found."

    async def run(self) -> AsyncGenerator[str, None]:
        """
        Async generator yielding SSE events:
          - __agent_start:document_analyst
          - __agent_thinking:{url_encoded_text}
          - __agent_tool:search_document_chunks
          - __agent_end:document_analyst
          - RESULT:{result_text}   ← consumed by chat_service, NOT emitted to client
        """
        # 1. yield __agent_start
        # 2. Build isolated messages: [system_prompt, user_task]
        # 3. Agentic loop (max 3 iterations):
        #    a. Call Groq with TOOL_DEFINITIONS, tool_choice="auto"
        #    b. If finish_reason == "stop": yield __agent_end, yield RESULT:{content}
        #    c. If finish_reason == "tool_calls":
        #       - yield __agent_thinking:{first_content_chunk} if content present
        #       - For each tool_call: yield __agent_tool:{name}, execute, append result
        #    d. If max iterations reached: yield __agent_end, yield RESULT:{last_content}
```

### Task 3 — Backend: Extend `chat_service.py`

**File:** `backend/app/services/chat_service.py`

Modify the tool execution block in `stream_chat()` (currently after Pass 1 `finish_reason == "tool_calls"`):

```python
for tool_call in tool_calls:
    tool_name = tool_call.function.name
    tool_args = json.loads(tool_call.function.arguments)

    if tool_name == "analyze_document":
        # Bridge sub-agent generator to main SSE stream
        agent = DocumentAnalystAgent(
            document_id=tool_args["document_id"],
            task=tool_args["task"],
            user_id=user_id,
        )
        tool_result = ""
        async for event in agent.run():
            if event.startswith("RESULT:"):
                tool_result = event[len("RESULT:"):]
            else:
                yield f"data: {event}\n\n"  # __agent_start, __agent_thinking, etc.
    else:
        yield f"data: __tool:{tool_name}\n\n"
        tool_result = await execute_tool_call(tool_name, tool_args, user_id)

    tool_messages.append({
        "role": "tool",
        "tool_call_id": tool_call.id,
        "content": tool_result,
    })
```

### Task 5 — Frontend: Extend `api.ts`

```typescript
interface StreamCallbacks {
  onChunk: (token: string) => void
  onSources?: (count: number) => void
  onToolStart?: (toolName: string) => void           // __tool:{name}
  onAgentEvent?: (event: AgentEvent) => void         // __agent_*

}
```

Parse new events in the SSE loop:
```typescript
if (payload.startsWith("__tool:")) {
  onToolStart?.(payload.slice(7))
  continue
}
if (payload.startsWith("__agent_start:")) {
  onAgentEvent?.({ type: 'start', agentName: payload.slice(14) })
  continue
}
if (payload.startsWith("__agent_thinking:")) {
  onAgentEvent?.({ type: 'thinking', agentName: 'document_analyst', text: decodeURIComponent(payload.slice(17)) })
  continue
}
if (payload.startsWith("__agent_tool:")) {
  onAgentEvent?.({ type: 'tool', agentName: 'document_analyst', toolName: payload.slice(13) })
  continue
}
if (payload.startsWith("__agent_end:")) {
  onAgentEvent?.({ type: 'end', agentName: payload.slice(12) })
  continue
}
onChunk(payload)
```

### Task 6 — Frontend: Extend `useChat.ts`

**File:** `frontend/src/hooks/useChat.ts`

Add state:
```typescript
toolEvents: ToolEvent[]          // active tool calls during current stream
agentEvents: AgentEvent[]        // active sub-agent events (cleared per tool call)
```

Wire up new callbacks:
```typescript
onToolStart: (toolName) => {
  setToolEvents(prev => [...prev, { toolName, agentEvents: [] }])
},
onAgentEvent: (event) => {
  setToolEvents(prev => {
    const updated = [...prev]
    const last = updated[updated.length - 1]
    if (last) last.agentEvents = [...last.agentEvents, event]
    return updated
  })
},
```

Reset `toolEvents` on `onDone` and on new message send.

## Notes & Decisions

- **No new DB tables needed.** Sub-agent events are ephemeral UI state; only the final tool result is stored in `messages` as the assistant turn content.
- **Model reuse.** Sub-agent uses the same `llama-3.1-8b-instant` model — no extra cost configuration.
- **Max 3 iterations** in sub-agent loop prevents infinite tool-calling cycles. After 3, uses last available content as result.
- **URL-encode thinking text** in `__agent_thinking:` to prevent newlines from corrupting SSE framing. Frontend decodes with `decodeURIComponent`.
- **Context isolation is explicit:** `DocumentAnalystAgent` builds its own `messages` list from scratch — it does not receive `chat_history` from the parent.
- **Graceful degradation:** If `DocumentAnalystAgent.run()` raises internally, it must yield `RESULT:I was unable to analyze this document.` rather than propagating the exception.
- **Fix existing bug (Task 5):** `__tool:*` events currently fall through to `onChunk()` in `api.ts` and render as raw text in the chat. This is fixed as part of the api.ts refactor.
