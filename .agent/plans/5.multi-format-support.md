# Module 5: Multi-Format Support

**Complexity: Medium**

## Context

The current ingestion pipeline only supports PDF via `pypdf`. Module 5 extends it to handle PDF, DOCX, HTML, and Markdown using `docling` as a unified document parser. The PRD explicitly specifies docling for this module. The goal is to replace the Stage 1 pypdf parser with a format-aware parsing service while keeping everything else (metadata extraction, chunking, embedding, storage) unchanged.

## Task 2 — Create `backend/app/services/parsing_service.py`

Follows the exact singleton + async executor pattern from `embedding_service.py` (`_model` / `_get_model()` / `run_in_executor`).

```python
import asyncio
import os
import tempfile
from pathlib import Path
from docling.document_converter import DocumentConverter

_converter: DocumentConverter | None = None


def _get_converter() -> DocumentConverter:
    global _converter
    if _converter is None:
        _converter = DocumentConverter()
    return _converter


async def parse_document(file_bytes: bytes, filename: str) -> str:
    """
    Parse PDF, DOCX, HTML, or Markdown into markdown text using docling.
    Runs synchronous conversion in a thread executor.
    Raises ValueError on failure with a descriptive message.
    """
    suffix = Path(filename).suffix.lower() or ".tmp"
    tmp_path = None

    try:
        # delete=False required on Windows — OS holds file lock while open
        with tempfile.NamedTemporaryFile(suffix=suffix, delete=False) as tmp:
            tmp.write(file_bytes)
            tmp_path = tmp.name

        converter = _get_converter()
        loop = asyncio.get_event_loop()
        result = await loop.run_in_executor(
            None, lambda: converter.convert(tmp_path)
        )
        return result.document.export_to_markdown().strip()

    except Exception as exc:
        raise ValueError(f"Failed to parse '{filename}': {exc}") from exc

    finally:
        if tmp_path and os.path.exists(tmp_path):
            os.unlink(tmp_path)
```

**Key decisions:**
- `delete=False` + `finally` cleanup is mandatory on Windows (OS lock prevents docling opening the same path while the `with` block is open).
- `export_to_markdown()` preserves headings, lists, tables — better structure for the fixed-size chunker and metadata extractor.
- Any docling exception becomes a `ValueError` with filename + original message, which surfaces cleanly in the UI via ingestion_service's outer `except` block.
